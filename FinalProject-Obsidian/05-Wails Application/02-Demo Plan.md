## Demo Dataset

- รูปปกติอย่างน้อย 5 รูป
- ไฟล์ชื่อซ้ำ 1 รูป
- ไฟล์ที่ไม่ใช่รูป 1 ไฟล์
- รูปที่ลบจาก Destination เพื่อสาธิต Missing 1 รูป
- รูปที่ AI วิเคราะห์สำเร็จ 1 รูป
- กรณี AI ล้มเหลวหรือ Mock Error 1 รูป

## Demo Safety

- ใช้โฟลเดอร์ทดสอบ ไม่ใช้รูปต้นฉบับสำคัญ
- เตรียม Offline/Mock Result หาก API ใช้งานไม่ได้
- ตรวจ API Quota ก่อน Demo
- Build และเปิดแอปก่อนถึงคิว
- เตรียม Source/Destination ที่ Path สั้นและอ่านง่าย
- ซ้อมตามลำดับเดิมอย่างน้อยสองครั้ง
